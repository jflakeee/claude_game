# 2차 이후 확장 구현·검증 기록

후속 전체 재감사에서 발견한 연결 누락을 추가 수정했다. 최신 결과는 [전체 설계 재감사 기록](reaudit/review.md)을 따른다(116개 테스트, 방치 상태 효과·장비 제작 경로·화면 회전 보완).

기준: [최초 설계의 2차 이후 로드맵](../../superpowers/specs/2026-10-02-idle-vampire-hybrid-game-design.md), [구체화한 확장 사양](../../superpowers/specs/2026-10-04-expansion-design.md).

완료 상태: 위 범위 구현, 108개 자동 테스트, 기능 UI 조작·보스 패턴·공개 배포 시각검증 모두 통과. 각 최종 브라우저 검증의 페이지 오류 0건.

## 구현 범위

| 설계 항목 | 구현 및 확인 내용 |
|---|---|
| 룬워드 | 화염·서리·수호 룬, 순서가 있는 2소켓, 잿불·서리장막·여명 조합과 전투 효과, 조합표와 현재 소켓 미리보기 |
| 큐빙 | 같은 등급의 감정된 빈 소켓 장비 3개 승급, 장비 분해, 옵션 재추첨, 룬 3:1 변환, 재료 부족 시 원상 유지 |
| 감정 | 희귀 이상 미감정 드롭, 감정 비용/접두 옵션 공개, 감정 전 장착·제작·경매 등록 차단 |
| 등급 세분화 | 기존 영웅 유지 + 세트/고유. 별빛 세트 2/3부위 효과, 고유 치명타 효과. 6등급 확률 총합 100%, 저장 마이그레이션 |
| 심화 스킬 | 8종, 레벨·선행 스킬 조건, 포인트 소비, 관통·흡혈·시너지, 오라/저주 각각 1개 선택 |
| 저주·오라·군집 | 범위 오라, 4초 적 저주, 우두머리+추종자 군집, 보라색 저주 범위와 플레이어 쇠약, 범위 이탈 시 해제 |
| 보스 아레나 | 별도 입장 버튼/봉인 바닥/체력바, 원형 폭발·방사 탄막·직선 돌진의 1.25초 예고, 체력 절반 2단계, 다음 수문장 강화 |
| 보스 정산 | 실제 처치만 승리, 시간 초과 실패, 영웅 장비·룬·골드·경험치, 중복 지급 방지, 중도 이탈 정산 |
| 거래 고도화 | NPC 재고 구매·매각·되사기, 입찰·경쟁 입찰·예치/환불·즉시 구매·낙찰 보관함, 출품·취소·유찰 반환·수수료 정산, 재접속 후 정산 |

거래는 기존 서버 없는 1인용 설계에 맞춘 **NPC 상인 및 NPC 경매**이다. 실제 사용자 간 온라인 거래나 계정 서버는 포함하지 않으며 화면에도 이를 명시한다.

## 검증

- 자동 테스트: 17개 파일, 108개 통과. 기존 1레벨 3분 생존 회귀, 소비 실패/중복 지급/가방 가득 참/구형 저장/경매 재접속 정산을 포함한다.
- 빌드 성공. Phaser 포함 JS 번들 크기 안내 경고는 남아 있으며 실행 오류는 아니다.
- `visual-expansion.cjs`: 격리된 레벨 10 저장본으로 실제 UI를 통해 감정→룬워드→재추첨→분해→합성→스킬→상인→경매→재접속을 조작한다. 보스전은 시간 가속 없이 이동 입력으로 플레이한다.
- `visual-encounters.cjs`: 낮은 공격력/선택 패턴 등 명시적 검증용 상태를 사용한다. 예고 화면만 정지 캡처하며, 발동과 피해는 실제 게임 프레임으로 확인한다. 폭발·탄막·돌진, 폭발 피격, 군집 저주, 보스 2단계, 제한시간 경계에서 실패 및 승리 보상 미지급을 통과했다.
- 제작·경매·스킬·보스 스크린샷을 직접 열어 배치와 표시를 확인했다. 경매 카운트다운이 버튼 DOM을 교체하던 문제를 수정했다.
- 공개 사이트 검증 스크립트는 새로운 저장 상태와 고등급 장비 검증용 저장 상태를 별도 브라우저 컨텍스트에서 사용한다. 실제 이용자의 저장소는 수정하지 않는다.
- Chromium 모바일 뷰포트·터치 에뮬레이션 및 데스크톱 검증이다. 실제 iPhone/Safari 기기 테스트를 의미하지 않는다.
