# 전체 설계 재감사

완료: 발견한 7개 연결 문제를 수정했고, 116개 테스트·개발 화면·공개 배포 화면·보스 3패턴 재검증이 모두 통과했다. 최종 브라우저 검증 오류는 0건이다. 배포 번들은 `index-DPHAMAud.js`이며 게임 저장소와 커스텀 도메인 저장소 모두 Pages 빌드 완료를 확인했다.

사용자의 지시에 따라 결정이 필요한 사항은 기존 서버 없는 1인용 구조에 맞는 권장안으로 진행했다. 기존 기능의 존재 여부뿐 아니라 실제 플레이 경로와 양쪽 전투 모드의 연결을 다시 검토했다.

## 발견 후 수정한 항목

| 항목 | 발견 내용 | 수정 |
|---|---|---|
| 방치 저주·오라 | 한기/룬 둔화가 적의 행동을 바꾸지 않았고 효과 표시가 부족했다. | 적 공격 주기를 둔화하고 4초 지속시간/해제를 적용. 오라·저주 범위와 선택 효과를 표시. |
| 피해·흡혈 | 방치 분쇄 저주가 첫 타격부터 적용되고 흡혈이 초과 피해까지 계산됐다. | 명중 후 저주, 후속 타격 추가 피해. 실제 남은 적 체력만 흡혈에 반영. |
| 장착 장비 제작 | 가방 아이템만 제작할 수 있지만 장착 장비를 가방으로 옮길 수 없었다. | '가방으로' 기능 추가. 가방이 가득 차면 장착 유지, 중복 이동 방지. |
| 제작 사전 안내 | 합성 시 실제 소모될 장비를 확인하기 어려웠다. | 조건에 맞는 첫 3개 이름·개수·비용·결과 등급/슬롯 표시. 선택 장비의 감정비·분해 보상도 표시. |
| 획득 알림 | 첫 장착 슬롯의 교체만 감시하여 미감정 희귀 드롭을 알리지 못했다. | 획득 이벤트에서 희귀 이상 알림 생성. 가방 감정 안내 및 가방 초과 골드 환산 안내. |
| 가챠 결과 | 가방 초과로 환산한 미감정품에도 감정 버튼이 표시됐다. | 실제 가방에 존재하는 아이템에만 감정 버튼 표시. |
| 전투 화면 변경 | 플레이어만 크기 변경을 따라가고 보스·탄막·예고/돌진 좌표는 남아 있었다. | 전체 전투 객체와 목표 좌표를 함께 변환. HUD 아래 전투 영역을 기준으로 가로/세로 배치. |

## 설계 항목별 근거

- 방치 횡스크롤·자동 전투·스테이지 순환·성장: `IdleScene`, `idleCombat`, `idleEffects`, `leveling`.
- 액션 영역 탭·전체화면 생존·이동 입력·자동 공격·3분 승리/사망/이탈: `CombatScene`, `arena`, `survivalCombat`, 기존 회귀 및 시각검증.
- 공유 재화·중단 정산·저장 복원·가방 초과 처리: `combatLifecycle`, `persistence`, `inventory` 및 중복 정산 테스트.
- 장비·자동 장착·스크랩북 복원·관리 패널 최소화·설정·가챠: `BottomPanel`, `items`, `scrapbook`, `shop` 및 UI 조작 검증.
- 룬워드·큐빙·감정·6등급·세트/고유: `crafting`, `expansion`, `dropTable`, `effectiveStats` 및 확장 테스트.
- 선행 스킬·시너지·저주·오라·몬스터 군집: `skills`, `idleEffects`, `arena`, `encounters`.
- 보스 아레나·3패턴·단계 전환·승리 보상·시간 초과 실패: `encounters`, `arenaLayout`, `combatLifecycle` 및 패턴 시각검증.
- NPC 거래/경매: `market` 및 예치금·환불·출품·수령·재접속 정산 테스트. 실제 사용자 간 온라인 거래는 이 1인용 설계에 포함하지 않는다.

## 검증

- 18개 테스트 파일, **116개 통과**. 새 회귀 8개는 방치 둔화/흡혈, 장비 이동/가방 초과, 알림, 합성 재료, 전장 좌표, 가로 화면, 환산품 UI를 검증한다.
- `visual-design-audit.cjs`: 장착 해제 → 룬워드 제작 → 실제 재료 미리보기 → 합성 → 재장착 → 방치 효과 → 보스 화면 크기 변경 → 이탈을 조작한다.
- 개발 환경에서 저주 표시와 크기 변경을 정확히 캡처할 때만 테스트 상태와 일시정지를 사용한다. 최종 배포 검증에서는 개발 훅을 사용하지 않는다.
