## 검증 증거

배포 대상 구현은 전체 Vitest 20파일 / 132개와 Vite 빌드를 통과했다. 이후 변경은 배포 QA 스크립트·기록이다.

[공개 Playwright 결과](results.json): HTTP 200, 새 번들, 데스크톱 보스 및 모바일 생존 전투 복귀, 모션 설정 저장·복원, 포털 iframe 로딩, 프로덕션 디버그 훅 부재를 확인했다. 별도 격리 브라우저에서는 구 저장 42G와 원본 백업 보존, 실제 설정 버튼의 저장 실패 안내·재시도·재접속 복원, 손상·미지원 기록 보존 및 시작 차단을 확인했다. 페이지 오류는 0개였다.

데스크톱·모바일·포털·저장 실패·미지원 기록 캡처를 열어 확인했다. fixture는 전용 브라우저 컨텍스트의 합성 게임 저장만 사용했다. 일반 사용자의 저장이나 로그인 상태에는 접근하지 않았다.

실패 주입은 설정 버튼 클릭 순간에 시작하고 재시도 클릭 순간에 해제해 주기 저장과 시험 동작의 경쟁을 제거했다. 캡처 중 자연스럽게 전투가 끝날 수 있어 나가기 키보드 조작 또는 실제 열린 결과 화면을 거쳐 복귀하도록 검증했다. 결과 화면이 없는 예상 밖 오류는 통과로 처리하지 않는다.

## 롤백과 한계

롤백이 필요하면 각 배포 저장소에서 이번 배포 커밋을 revert해 이전 index.html과 자산 구성을 복원하고 같은 gh-pages 원격에 push한다. 도메인 저장소는 claude_game 경로 변경만 되돌린다. 저장 데이터와 legacy 백업은 삭제·역이행하지 않는다. 이전 게임은 추가 메타데이터를 복원하지 않으므로 저장 보호 기능이 사라질 수 있다.

이번 배포 범위는 저장 보호 기반이다. 상자 보호 수령·비용/보상 거래·독립 탐험·다중 탭 잠금은 아직 구현되지 않았다. 실제 iOS/저사양 Android 성능과 장기 사용자 지표를 이번 자동 브라우저 결과로 대체하지 않는다. 기존 500KB 초과 JS 번들 경고는 남아 있다.
