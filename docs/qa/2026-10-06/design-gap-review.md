# 재설계 대비 미구현 작업 검토

검토일: 2026-10-06. 기준 문서: [재설계 가능성 분석](../../research/project-application/redesign-feasibility.md), [16개 적용 로드맵](../../research/project-application/roadmap.md). 코드, 기존 화면 캡처, 배포 기록을 대조했다. 이번 검토에서는 테스트를 다시 실행하지 않았다.

## 판정

권장 B안은 **대표 구간이 구현된 상태**다. 전체 재설계 완료로 볼 수는 없다. 준비·장비·전투 진입, 일부 주인공/슬라임 자세, 돌진·방사 위험 표시, 짧은 보스 소개가 있다. 여러 설계 항목은 부분 구현 또는 제안 수준에 남는다.

| 설계 항목 | 현재 상태 | 남은 차이 |
|---|---|---|
| 넓은 화면 준비·장비 구성 | 대표 구간 완료 | 결과/획득 화면까지 준비 흐름 연결, 포털 실제 실행 검토 |
| 전투 폭 정책 | 미완료 | 탐험은 넓어졌지만 전투 캔버스 폭을 520px로 유지하며 논리 전투 좌표와 표시 좌표를 분리하지 않음. 따라서 설계가 제기한 넓은 화면 정책 판단은 해결되지 않음 |
| 장비 전후 비교·자동 장착 보호 | 대표 구간 완료 | 결과 보상에서 같은 비교·선택 흐름으로 이어지지 않음. 장기 저장 이행과 복수 장비 상황 검토 기록 없음 |
| 출전 준비·첫 성장 안내 | 부분 | 출전 선택은 명시적이나 첫 획득→비교→장착을 이끄는 도움말/목표 흐름은 없음 |
| 위험 표현 | 부분 | 돌진·방사 예고는 시각 구분. `drawEffects` 안에 의미·모양·판정이 여전히 직접 묶여 있고, 모든 위험 유형의 판정 디버그 중첩 및 플레이어 실제 접촉 크기 확인은 없음 |
| 캐릭터 동작 프레임 | 부분 | 주인공 이동·준비·공격·피격과 슬라임 이동·피격. 박쥐·해골·수호자 동작, 별도 표시 루트, 퇴장 자세, 큰 원화 해상도 비교는 없음 |
| 보스 소개 | 부분 | 정지 타이머·건너뛰기·감소 모션·화면 페이드. 시선 연출, 소리 연결, 재도전용 단축, 소개 완료와 실제 공격 개시의 모든 상태 조합 확인은 없음 |
| 배경 공간감 | 부분 | 반복 벽 대비를 낮추고 아치 장식을 추가. 원경/벽/바닥의 독립 레이어와 시차는 없음 |
| 위험/HUD 정보 우선순위 | 부분 | HP 이력바와 경고 문구가 존재. 다수 경고의 우선순위·합산 및 효과 밀집 시 가독성 기준은 없음 |
| 애니메이션 수명/취소 | 부분 | 감소 모션, 씬 종료 정리, 일부 동시 표시 상한이 있음. 공통 표현 수명/우선순위 정책과 resize·중단·스킵 전 상태 복원 계약은 없음 |
| 재현/성능 기반 | 미완료 | 고정 위험 캡처와 브라우저 fixture는 있으나 반복 입력 세트, 느린 프레임/메모리/실기기 측정은 없음 |
| 아트 스타일 규칙 | 미완료 | 현재 코드에 팔레트와 픽셀 질감이 있으나 모든 자산에 적용되는 윤곽·명암·효과 형태 지침이 정식 기준으로 고정되지 않음 |
| 적 역할과 페이싱 | 조사/실험 전 | 적들은 접근하는 행동이 중심. 역할별 행동과 전투 강약 실험은 로드맵의 후속 항목 |
| 보상 분포 모델 | 검토 전 | 시각 재설계 대표 작업과 별도인 경제·장기 획득 분포 계산은 남음 |
| 강한 타격 정지 연출 | 미채택 | 로드맵 P3의 선택 실험. 현재 범위에서 필수 누락은 아님 |

## 우선순위 권고

1. **P0 — 기준 전투 영역 정책 확정:** 520px 고정 영역과 큰 화면 확대 중 하나를 선택해 논리 좌표, 터치/키보드 입력, 위험 폭, 리사이즈 동작을 문서화한다. 지금은 기존 폭을 보존하는 선택만 구현된 상태다.
2. **P0 — 위험 신호의 판정 일치 확인:** 공격별 예고·실제 접촉 크기·플레이어 반응을 한 장면에서 겹쳐 본다. 의미 정의를 코드에서 분리하면 다음 적과 화면에도 같은 규칙을 적용하기 쉽다.
3. **P1 — 프레임/표시 계층 확장:** 박쥐·해골·수호자와 퇴장 자세를 같은 픽셀 규칙으로 제작한다. 판정 좌표와 스프라이트 오프셋을 분리하고 실제 크기에서 비교한다.
4. **P1 — 획득에서 결과까지 연결:** 자동 장착 여부, 잃고 얻은 세트/룬 효과, 보관 후 다음 행동을 결과 화면에 연결한다. 첫 플레이의 장착 안내도 함께 다룬다.
5. **P1 — 배경 및 효과 정책:** 독립 레이어, 낮은 시차, 줄어든 모션 대안을 만들고, 경고 우선순위와 여러 효과의 겹침 규칙을 정한다.
6. **P2 — 재현성·실기기 통합 검토:** 고정 시나리오와 대표 저사양 모바일을 정해 프레임 저하, 화면 크기, 저장 복귀, 포털 내 실행을 확인한다.
7. **P2+ — 선택적 내용 실험:** 적 역할, 보상 분포, 타격 정지는 별도 비교안으로 검증한다. 표현 작업과 밸런스 변화를 섞지 않는다.

## 배포 상태 메모

기존 배포 기록의 “queued”는 현재 기준으로 오래된 상태다. 게임 Pages의 배포 작업 `37373169826`은 성공했다. 도메인 저장소 작업 `37373197368`의 Pages `deploy` 단계도 성공했으나, 뒤의 `report-build-status` 단계가 취소되어 전체 실행 결론은 `failure`다. 공개 게임 index는 `index-Dy2G0TBs.js`를 참조하는 것을 확인했다. 포털 자체 index도 응답하지만, 이번 읽기 확인만으로 iframe 안의 새 버전 실제 조작까지 검증한 것은 아니다.
